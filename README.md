# dev-learning
My Developer Journey

백엔드 개발자로서 AWS, 네트워크, 데이터베이스, 자료구조 등의 개념을 학습하고 코드와 실험으로 검증하는 Public GitHub 학습 저장소다.

## 학습 방식

- ChatGPT: 개념 학습, 질의응답, 자신의 설명에 대한 피드백을 진행한다.
- Codex: 실습 코드를 작성하고 실행 결과와 검증 근거를 문서화한다.
- 개념을 읽거나 답변을 받은 사실과 직접 실행해 확인한 사실을 구분한다. 사용자가 직접 설명하거나 검증한 근거가 있어야 완료로 기록한다.

## 현재 구조

```text
dev-learning/
├── README.md
├── AGENTS.md
└── topics/aws/saa/
    ├── roadmap.md
    ├── progress.md
    ├── notes/
    │   └── .gitkeep
    └── labs/
        └── .gitkeep
```

- [학습 에이전트 지침](AGENTS.md)
- [AWS SAA-C03 8주 계획](topics/aws/saa/roadmap.md)
- [학습 진행 기록](topics/aws/saa/progress.md)
- `notes/`: 자신의 설명, 공식 문서 출처, 남은 질문을 기록한다.
- `labs/`: 실습 코드, 실행 방법, 기대 결과와 실제 검증 결과를 기록한다.

네트워크, 데이터베이스, 자료구조의 별도 폴더는 해당 학습을 시작할 때 필요한 범위만 추가한다.

## 기록과 검토

1. 계획에서 학습 항목을 고르고 공식 문서를 읽는다.
2. 자신의 말로 설명하고 피드백과 미해결 질문을 노트에 남긴다.
3. 실습 전 예상 결과를 적고, 실행 후 실제 결과와 차이를 기록한다.
4. 근거를 연결해 진행 표를 갱신한다. AI가 작성한 문서나 코드만으로 완료 처리하지 않는다.
5. 커밋 전 `git status --short`와 `git diff`로 변경을 확인하고, 새 파일도 직접 읽어 검토한다.

Public 저장소에는 회사 내부 정보, 개인정보, AWS 자격 증명을 기록하지 않는다. 코드, 로그, 스크린샷에도 같은 원칙을 적용한다.

현재는 학습 문서와 빈 실습 디렉터리만 준비한다. AWS 리소스를 생성하거나 배포하지 않는다. 향후 AWS 실습은 사용자가 해당 실행을 요청한 뒤 비용, 권한, 정리 방법을 확인하고 진행한다.
