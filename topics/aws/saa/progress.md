# AWS SAA-C03 학습 진행 기록

[8주 계획](roadmap.md)에 맞춰 기록한다. 초기 상태는 모두 미시작이며 학습이나 실습을 수행했다는 의미가 아니다.

## 기록 기준

- 학습 상태: `미시작` / `진행 중` / `복습 필요` / `완료`.
- 이해 수준: `0 미확인` / `1 용어 설명` / `2 원리·차이 설명` / `3 요구사항에 적용하고 대안 비교`. 사용자의 실제 설명을 근거로 기록한다.
- 실습 여부: `미실행` / `로컬 실행` / `AWS 실행` / `해당 없음(개념·설계만)`. 설계 검토나 문서 읽기를 실행으로 표시하지 않는다.
- 검증 상태: `미검증` / `AI 실행만 확인` / `사용자 검증`. AI 실행만 확인한 경우 사용자가 결과를 해석하고 검증하기 전까지 완료로 올리지 않는다.
- 개념만 다루는 항목은 사용자의 설명과 피드백 근거가 있어야 완료다. 실습을 포함한 항목은 사용자가 직접 실행하거나 결과를 검토하고 판정 근거를 설명해야 완료다.
- 노트·실습 근거에는 상대 링크와 사용자 설명 또는 검증 날짜를 남긴다. 예상 결과와 관찰 결과, 실행 환경과 한계를 구분한다.
- 주차별 행은 시작용 요약이다. 일부만 이해했거나 검증했으면 항목별로 행을 나누고 주차 전체를 완료하지 않는다. 시간 경과나 문제 정답률만으로 완료 처리하지 않는다.
